# 一级标题

段落之间用空行分隔。

第二段。_斜体_，**加粗**，以及 `等宽字体`。项目列表
如下所示：

- 这个
- 那个
- 另一个

请注意 —— 不考虑星号 —— 实际文本
内容从第 4 列开始。

> 块引用
> 像这样编写。
>
> 如果你愿意，它们可以跨越多个段落。

使用 3 个破折号表示长破折号。使用 2 个破折号表示范围（例如，“都在第 12--14 章”）。三个点 ... 将被转换为省略号。
支持 Unicode。☺

## 二级标题

这是一个数字列表：

1. 第一项
2. 第二项
3. 第三项

再次注意实际文本是如何从第 4 列开始的（距离左侧 4 个字符）。这是一个代码示例：

    # 让我重复一遍 ...
    for i in 1 .. 10 { do-something(i) }

正如你可能猜到的，缩进了 4 个空格。顺便说一下，除了
缩进块之外，你还可以使用定界块，如果你喜欢的话：

```
define foobar() {
    print "欢迎来到风味之国！";
}
```

（这使得复制和粘贴更容易）。你可以选择为定界块标记语言，以便 Pandoc 进行语法高亮：

```python
import time
# 快，数到十！
for i in range(10):
    # （但不要*太*快）
    time.sleep(0.5)
    print i
```
